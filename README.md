# 🧪 Portfólio QA – BlazeDemo

Este repositório reúne um projeto prático de Quality Assurance aplicado ao site BlazeDemo, com foco no desenvolvimento de uma abordagem estruturada de testes, utilizando técnicas de análise, priorização e execução.

O objetivo é demonstrar não apenas a execução de testes, mas principalmente o **raciocínio analítico e estratégico de QA**, desde o entendimento do usuário até a identificação de riscos e validação do sistema.

---

## 🧠 Abordagem de QA aplicada

Para este projeto, segui uma abordagem estruturada baseada em etapas:

1. **Entendimento do usuário (Persona)**  
   Defini perfil de usuário para compreender comportamentos, necessidades e possíveis pontos de falha na jornada.

2. **Mapeamento do sistema (Mapa Mental)**  
   Estruturei funcionalidades e fluxos do sistema para garantir visão ampla e cobertura de testes.

3. **Análise de risco (Matriz de Risco)**  
   Identifiquei áreas críticas com maior impacto para o negócio, priorizando os testes mais relevantes.

4. **Priorização (Análise de Pareto)**  
   Foquei nos cenários com maior potencial de falha e impacto, otimizando o esforço de teste.

5. **Otimização de cenários (Pairwise Testing)**  
   Apliquei técnica de combinação para reduzir o número de testes mantendo boa cobertura.

6. **Execução (Teste Exploratório)**  
   Realizei testes baseados em exploração, simulando comportamento real do usuário e identificando possíveis defeitos.

---

## 📁 Estrutura do Projeto

Explore as pastas para entender cada etapa do processo:

- **01-Mapa-Mental** – Análise de cenários e fluxos do sistema  
- **02-Persona** – Definição de perfil de usuário  
- **03-Matriz-de-Risco** – Priorização de testes baseada em impacto  
- **04-Pareto** – Identificação dos pontos mais críticos  
- **05-Pairwise** – Otimização de combinações de teste  
- **06-Exploratory-Testing** – Execução de testes, evidências e documentação
